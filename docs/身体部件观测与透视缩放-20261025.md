## 已实现的能力

参考 v2 可附 `parts`。每个部件保持固定解剖身份，记录身体刚性切片、服装或未知来源，按边界顺序标注 `outline`，并明确采样误差 `radius`；节点另附 `uncertaintyRadius` 像素误差圆。已有 `confidence` 不能自动换算为像素误差。

`spine_analyze_reference_parts` 计算端点误差对方向的影响，以及等弧长轮廓采样的 PCA 主轴、退化程度和误差敏感度。它不会自动识别轮廓，也不保证单张图片能恢复三维方向。端点误差圆缺失/重叠、近圆轮廓或服装外缘时，只要两个既有节点可用，就返回两点连线的 `estimated` 结果；误差范围未知时保持 null。可靠轮廓与可靠端点发生冲突时保留冲突供复核，不自动选择能过门禁的那一份。

声明部件后，参考图绘制误差圆、轮廓和主轴，回退连线另用黄色虚线标出。可靠主轴与 runtime **视觉关节**的轴比较，计入轮廓不确定性后仍须满足原 15°；两点回退则沿用原 segment 方向门禁，新增轮廓 certainty/axis 仅作诊断，不形成重复阻塞。参考批准仍需显式审查，记录所用方法、可靠程度及策略 v2；旧图与旧批准不能自动继承。主轴是无向轴，不能推断前后；离散可用性不进入最小二乘残差。

语义姿态新增 `frame.perspective`：

```json
{
  "mode": "diagnostic",
  "limb": "leftArm",
  "upper": 0.9,
  "lower": 0.85,
  "basis": "固定躯干与手目标，检验臂段纵向缩短对肘位的影响；不声称恢复真实深度"
}
```

这是局部骨骼 X 轴缩放倍率，**不等同于最终世界空间投影长度的相同比例**：父缩放、子旋转和网格权重会影响实际结果。报告另列实际臂段长度。`0 < upper/lower <= 1` 只是数学输入范围，不是该角色已验收的美术范围。

缩放在实际官方 runtime 中参与求解，端点方向通过真实矩阵求逆，固定弯曲分支内最多 60 次迭代。上臂支持正常继承和 npc1 现有的 `noRotationOrReflection`；下段和手须正常继承，镜像、shear、奇异变换及臂链被现有约束/follow 接管时拒绝。末端、方向与弯曲分支在关节限制应用后再次回读。

底层输出包含 setup 相对的 `scale` 倍率；Host Canvas 与只读 player 导出支持相同字段，并沿用全部骨骼矩阵/附件顶点回放误差不超过 `1e-4` 的核验。没有修改角色 setup、骨骼结构、皮肤、网格或约束。

## MCP 操作方式与边界

隔离 C2 attached 使用 `spine_adjust_pose`，必须携带当前完整 `expectedRevision`，省略 `outputPosePath`，通过 `patch.frame.perspective` 修改内存。默认 `dryRun:true`；`false` 后重新求解、发布并返回图。也可用 `spine_host_patch` 的 `setPosePerspective`，路径固定 `pose/frame/perspective`，`value:null` 表示恢复无缩放。撤销、重做与恢复均复核当前 profile；C1 拒绝扩展操作和透视编辑历史。

detached 可用 `spine_adjust_pose` 保存新的诊断修订，仍不得绕过 MCP 修改 Spine JSON。诊断姿态可在数值通过后通过 Host 的草稿保存取得新路径，但**不取得正式姿态批准或源动画提交资格**。即使伪造旧批准，`requireReviewedPoseData` 也拒绝透视诊断；不能作为标准站姿、组装正式 motion 或进入完整参考局部修正。动画构建层再次拒绝这些 frame。

`spine_analyze_reference_parts` 默认只读；`dryRun:false` 必须显式给 `reportPath`，只新建报告，不覆盖已有输入或报告。两个必要节点未知或可靠证据冲突时可以记录/出图，不能批准；单纯缺轮廓的两点估计允许按既有流程显式审查。

## 验证与保留问题

首轮缩放实现的 `npm run build` 和 `npm test` 通过，完整 **212/212** 回归；[当批实现证据索引](plans/host-perspective-implementation-20261025.json) 记录源码/编译模块和日志哈希，与实际 player 采集时的构建分别标识。新增测试覆盖端点误差放大、轮廓退化/冲突、未知拒批、真实 MCP 路径/不可覆盖、两种上臂继承与两种固定分支、实际缩放回读、不可达、Host 回放/撤销、失败诊断保存授权拒绝和正式批准拒绝。合成夹具不作为美术角色验收；当前策略 v2 的 213 项结果另见顶部。

回放新增可选 scale 字段后，黄金帧登记按代码哈希失效。重新登记前使用原始三张 player PNG/回读/快照重渲染验证：差异比例分别约 0.1523% / 0.0811% / 0.1465%，最大通道差均为 1，原 0.5% / 8 门限不变，所有基线图片与捕获记录字节不变。仅更新兼容登记，不为缩放新增黄金帧或视觉批准。

后续正式创作仍需：可确认的参考身体轮廓与连续帧证据；部件相对躯干的方向表达；角色特定的纵向/宽度/末端继承校准；在既有美术资源支持下处理视角与遮挡；连续动作稳定性与新负载性能；独立 Spine 编辑器导入。当前没有自动人体分割、三维重建、自动选择缩放倍率或自动批准参考姿态。
