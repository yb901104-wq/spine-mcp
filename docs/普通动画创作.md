# 普通动画创作

在 Agent 对话中直接提出任务，例如“用附件里的 WebP 做一段左踢，踢出后快速收腿”或“参考工程中的 attack 动画，新增一个收招更短的版本”。Agent 根据画面与工程数据选择操作，工具接收具体文件、对象、时间和数值。

## 配置

在现有 MCP 启动配置中设置 `SPINE_MCP_TOOL_PROFILE=authoring`。用本机 Spine 命令行读取和交付原生工程时，另设 `SPINE_EDITOR_CLI` 为 `Spine.com` 的绝对路径，例如 `D:/Program Files/Spine/Spine.com`。JSON 和 atlas 可以脱离编辑器制作及预览。

Codex 项目配置示例，按实际位置替换路径。

```toml
[mcp_servers.spine-authoring]
command = "node"
args = ["D:/AI_cc/spine-mcp/dist/server.js"]

[mcp_servers.spine-authoring.env]
SPINE_MCP_WORKSPACE = "D:/AI_cc/spine test"
SPINE_MCP_TOOL_PROFILE = "authoring"
SPINE_EDITOR_CLI = "D:/Program Files/Spine/Spine.com"
```

`authoring` 使用静态精简工具列表，含工程树、连接状态、工具目录和六项创作操作。原配置可以继续使用完整工具表与旧流程。用户提示词来自对话。

## 按需操作

| 操作 | 参数与行为 |
| --- | --- |
| `spine_read_reference_frames` | 给定 `filePath`，可用 `startFrame/endFrame` 或 `start/end` 选择范围，`offset/limit` 分页。时间使用秒，帧延迟使用毫秒。包含重复帧，`view:frames` 每次最多回传三张原图。 |
| `spine_inspect_project` | 给定 `filePath`。`view` 可查概要、骨骼、插槽、皮肤、附件、约束、时间线、单帧和 GIF。`skeleton` 选择骨架，`name` 查询指定对象，`animation/track/start/end` 限定时间线。可显式指定 atlas。 |
| `spine_open_animation_draft` | `mode:create` 创建新动画草稿，`mode:edit` 从指定已有动画开草稿。返回 `draftId`、`revision` 与 `candidateHash`。 |
| `spine_edit_animation_draft` | 给定 `draftId/expectedRevision` 和 `ops` 或 `history`。默认预演，`dryRun:false` 更新独立草稿。 |
| `spine_preview_animation_draft` | 给定草稿，可选历史 `revision`。支持状态、精确单帧、原速 GIF、联系表、骨架及切片顶点、同步对比。对比从 `compareRevision/referencePath/referenceManifestPath` 选一项，可给 `phaseMap`。`view:measure` 按明确的骨骼和区间回读位移与范围，可给诊断阈值。 |
| `spine_publish_animation_draft` | 明确指定草稿、当前修订、候选哈希、新输出目录和格式。默认 `spine`，也可选 `json`。默认预演，`dryRun:false` 实际交付。 |

关键帧操作使用 `track:{kind,name,timeline}`。骨骼轨道支持 `rotate/translate/scale/shear`，插槽支持 `attachment`，`drawOrder` 只填 `kind`。使用 `setFrames` 批量设帧，`deleteFrames` 删除闭区间，`copyFrames` 把区间复制到 `toStart`，`retimeFrames` 把区间映射到 `toStart/toEnd`。附件名称为 null 表示隐藏，写入时使用 4.1.24 的缺省 name 表达。

结构操作包括 `addBone`、`addSlot` 与 `addAttachment`。插槽默认隐藏。附件参数声明目标皮肤、插槽、区域名、输入图片及可选的 PNG 像素裁切。mesh 使用 Spine 的 UV、三角形、hull、顶点及权重编码。一个批次内可以引用本批新增的骨骼、插槽和附件。

换装可在独立草稿用 `replaceAttachment` 指定已有 `skin/slot/name`，并提供新 `region`、`imagePath`、可选 `crop` 和完整 region 或 mesh。替换保留附件引用身份，使用该皮肤的动画会显示新切片。使用新的 atlas 区域名，原文件、骨骼、插槽及动画关键帧保留。涉及 deform、链接网格或图片序列的附件需要先迁移相关数据。建议先看绑定姿势及有明显抬手、转身的动态 GIF，检查轮廓和遮挡衔接。

## 修订、观察与交付

每个草稿把源、候选与资源哈希绑定到独立 journal。Host 可以观察当前修订和预览状态，草稿工具也可以独立通过 stdio 运行。参考读取和视觉诊断由 Agent 按需调用。当前修订没有预览时，Host 标出上一有效画面的修订号。

同工作区的 WinForms「动画预览」自动显示草稿打开、实际编辑、渲染和实际发布的状态。当前修订预览就绪后自动同步 JSON、atlas、动画和皮肤。历史修订回看以及编辑、发布的 dryRun 保留当前观察状态。外部拆图和 CLI 转档可通过 `spine_preview_set_session` 补充阶段记录。

结构与格式错误会拒绝整批。数值、姿态和动作相似度由 Agent 与用户看画面判断。正式保存需要用户在对话中要求交付，Agent 随后指定精确候选和新目录。源工程只读。原生交付以 Spine 4.1.24 导出、导入和重新导出核验为依据，交付报告列明核验范围。原有严格重定向继续使用独立的证据、审查及写入协议。
