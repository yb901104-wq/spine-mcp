# 本轮实施与验收记录

## 已实施

- 离线 runtime + Canvas 贴图三角形渲染，生成 PNG 帧、contact sheet 和 GIF，不依赖 Computer Use。
- region/mesh、普通 clipping、颜色/透明度、混合模式；双色 tint 与嵌套 clipping 明确拒绝。
- 统一固定相机、可选局部 bounds、皮肤、PMA、FPS/帧数、缩放与背景；全部输入 hash 纳入缓存。
- 独立 jobId、status/manifest、数值报告、批处理报告、缓存锁、角色事务锁和目录隔离。
- 默认重定向（含 dryRun 候选）输出联系图；数值失败先返回报告，避免无意义生成完整 GIF。
- 参考 GIF disposal 合成、时间读取/缺失补正、重复帧、关键姿态、显式阶段标注与参考 manifest。
- 动画/参考并排对比、首帧叠加图、语义锚点轨迹和运动范围；同贴图同相机可输出首帧像素差异。
- Roots 优先登记、projectId、环境变量回退、异步项目隔离、符号链接边界和浏览器项目资源路由。
- 局部 motion 调整六项工具；底层 spine_set_curve；原有门禁、备份和工具兼容。
- 默认工具返回摘要；完整骨骼轨迹保存在 manifest，按需详细读取。

## 复核结果

npm run build 通过。npm test 当前55项通过，包括真实 MCP stdio、双角色 walk、同一求解器 idle/run、PNG/GIF 编解码、GIF 与动画对比、缓存、并发锁、符号链接越界和旧项目回归。

旧项目 Python 只读复核：walk 脚底8.383262e-7；explore-run 脚底0.000312149；idle 旋转0.301103°、位移0.058512、顶点0.954996。三者原骨骼、slots、skins、既有动画、atlas/PNG 不变，官方 runtime 均可加载、循环闭合。

官方 runtime 的旧 idle 实测：旋转0.409432°、位移0.059788、顶点0.915605。旋转未达到0.35°，不能把 Python 的通过结果当作 runtime 同一门槛通过。旧 walk runtime 有约1单位世界地面偏移，需要按角色地面约定校准。上述差异在测试诊断中明确输出，不改旧文件来掩盖差异。

## 待人工验收和限定

- Spine 编辑器导入未在本轮操作，仍需人工最终导入确认。
- GIF 的完整周期、接触/经过/抬脚语义和相机移动需 Agent 确认。不会把 GIF 像素当作精确 IK 数据。
- 非法结构/不可达等错误不继续叠加写入；恢复沿用既有备份流程。
- 进程崩溃后的残留锁先核对 pid 再人工清理。未进行自动抢锁或删除用户原有临时资料。
- .codex-temp、previews、backups、dist 等生成目录均排除提交，保留用户此前未提交的工程修改。
新增求解结果还用官方 runtime 对照稠密基线检查局部旋转/位移误差；因 runtime 曲线查表差异超限时最多收紧拟合三次，不放宽误差门槛。spine_run_validation_pipeline 默认增加联系图检查，preview:false 可只做原三项只读检查。
