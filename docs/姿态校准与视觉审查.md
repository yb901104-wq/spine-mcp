# 姿态校准与视觉审查

## 流程

图片参考先标注并审查，目标姿态随后适配：

```text
参考图片/WebP/GIF 拆帧
→ 参考关节观察记录 → 参考原图/连线图 → 参考审查
→ mapping 确认 → 标准站姿求解与审查
→ 目标关键姿态求解 → 上参考下目标的干净图和诊断图
→ 逐姿态审查 → v2 motion → dryRun 候选
→ 上下同步 GIF + 目标原速 GIF → 完整动画审查
→ 最终 reviewToken + expectedHash → 安全写入
```

参考审查不是自动识别模型：Agent 观察图片后填写坐标、可见性、置信度和依据。MCP 校验记录、渲染、绑定证据并强制流程，不能证明人工判断一定正确。

## 参考标注

`spine_create_reference_pose` 的 `observation` 含 `imagePath,time,facing,crop,height,groundY,basis,points`。

`points` 必须声明 `head,body` 和左右 `Shoulder,Elbow,Wrist,Hip,Knee,Ankle`：

```json
{
  "leftElbow": {
    "visibility": "occluded",
    "x": 243,
    "y": 124,
    "estimated": true,
    "confidence": 0.4,
    "basis": "衣服遮挡，根据上臂及手腕方向推测"
  },
  "rightElbow": { "visibility": "unknown" }
}
```

可见点必须有坐标；任何有坐标的点必须有 `confidence`（0–1）及依据。遮挡推测坐标必须 `estimated:true`；未知点不允许伪造坐标。

`spine_render_reference_pose_sheet` 输出上原图、下参考连线图，每页六列。实线连接可见点，虚线及空心圆表示遮挡推测，未知点不连接。绿左橙右；缩写 S/E/W/H/K/A 分别为肩/肘/腕/髋/膝/踝。左右按角色自身定义，转身或遮挡中的身份疑点写入依据。

`spine_review_reference_pose` 必须包含 `jointLocations,visibility,connections,facing,support,uncertainty` 六项、审查者、理由和问题列表。批准绑定标注、原图 hash 和渲染证据。新修订使用新文件路径。

## 标准姿态与目标关键姿态

标准站姿默认膝屈曲 ≤30°，双脚接地。特殊阈值必须显式指定理由；失败后不能自动放宽。资源指纹不包含 animation，因此仅增加其他动画不使标准站姿过期。

目标 `spine_create_pose_draft`/`spine_adjust_pose` 使用 `referencePosePath` 关联已审查参考。旧 inline `reference` 可读取、求解和诊断，但不能批准用于真实写入；需补独立参考审查。参考坐标不直接作为 IK 输入，Agent 根据目标比例建立 `normalizedSkeleton` 语义姿态。

`spine_solve_pose` 返回实际关节、屈曲、目标误差、可达性及握持误差。可选 `weapon` 是二维假想杆，不修改贴图；mapping 手部必须有 `gripPoint`。未指定的姿态属性从已确认标准站姿继承。

`spine_render_pose_comparison` 用 `stageIds,targetTimes` 显式选择阶段，每页六列，上参考下目标，固定角色比例、相机和地面。同时输出 clean/diagnostic；`region:[x,y,w,h]` 可输出局部放大。诊断中的目标是实际求解结果，紫方框是预期目标。

`spine_review_pose` 检查 `standingOrAction,silhouette,jointDirections,support,grip,occlusion,referenceDifferences`。数值失败、未解决问题或缺少图像证据不能批准。

## 候选动画与真实写入

`spine_build_motion_from_poses` 需要已批准标准站姿及关键姿态，唯一阶段 ID、递增时间，覆盖 0 与 duration。

`spine_retarget_motion` dryRun 可以诊断旧 motion，返回缺失审查；真实写入必须通过姿态门禁。有效姿态流程自动产生关键姿态对比、固定相机目标原速 GIF、候选 JSON 和验证报告。

`spine_render_animation_comparison` 使用单调阶段时间对应生成上下同步 GIF，不替代目标原速 GIF。`spine_review_animation` 检查 `transitions,timing,followThrough,keyPoses,loop`，返回最终批准 token；dryRun 返回的基础 token 不能直接提交。

修改参考图/标注、求解目标、mapping、资源或证据使对应确认失效。`preview:false` 不能绕过视觉门禁。批处理沿用同一门禁，单任务失败独立报告。旧底层微调不替代高层审查，改变已绑定候选后必须重新审查。
