## 源码与入口

- 工程：`src/projectSchema.ts`、`src/projectModel.ts`、`src/workspaceTools.ts`。
- 领域边界：`src/animationCommands.ts`、`src/animationKernel.ts`、`src/poseDigest.ts`；原 `poseWorkflow` 仍调用同一算法。
- 宿主：`src/hostDocumentStore.ts`、`src/hostEditorStore.ts`、`src/hostJournal.ts`、`src/writerOwnership.ts`。
- 桥接与呈现：`src/hostClient.ts`、`src/hostEvaluator.ts`、`src/renderSnapshot.ts`、`src/hostCapture.ts`、`src/captureEvidence.ts`、`src/goldenValidation.ts`。
- HTTP 与页面：`src/hostServer.ts`、`preview/host.html`。旧 `previewServer` 接口保持独立，WinForms 源码已通过双页签嵌入 Host；旧便携 exe 未更新。

先 `npm run build`，再 `npm run host` 启动独立观察服务。端口默认从本机 20000–59999 中选择；可使用 `SPINE_HOST_PORT` 指定。服务只绑定 `127.0.0.1`，私有发现文件位于工作区 `.spine-mcp/`。token 不放 URL；页面不包含 control 凭据。Windows 尝试用 `icacls` 保护凭据；控制文件保护失败时拒绝控制通道。

MCP 的发现顺序为 `SPINE_HOST_ENDPOINT` + `SPINE_HOST_TOKEN`、工作区端口文件、受控启动；`SPINE_HOST_AUTOSTART=0` 只探测并使用镜像。已知 attached 会话失联或仍有 attached 写入锁时保持冻结，不自动创建另一个写入者。外部选择的工作区使用 `SPINE_MCP_REGISTRY_ROOT` 保持原登记来源，不静默创建第二套登记。

该请求默认只预演。只有显式 `dryRun:false` 才创建根 `.spine-workflow.json`，且只允许预期不存在时原子发布；不会生成已确认 mapping、覆盖清单或修改角色文件。缺清单返回 legacy；损坏清单不降级 legacy；未知 schema 只返回诊断。

截至 2026-10-22 最新续验，`npm run build` 成功，完整 `npm test` 为 **131/131 通过**。新增严格并发读取、动态 junction 边界、首次完整相机/后续固定行为及局部修正取消前后评估次数检查。此前全量回归发现 dryRun 测试错误地比较 readiness 的 observedAt，已改为比较不含观测时刻的真实文档/事务状态；默认 dryRun 不修改文档、历史或 journal 的断言保留。

- 工程正反例：默认 dryRun 零写入、实际初始化、拒绝覆盖、登记/文档冲突、缺依赖、未知 schema、绝对路径、上级目录、符号链接和 atlas 页越界。
- 纯计算与回放：预加载后移走角色文件仍可计算；setup 非零位移/旋转、默认与替换皮肤、隐藏/替换附件及完整 drawOrder；未知骨骼增量字段拒绝。
- 版本：同路径幂等、A→B→A、外部漂移、显式重载、过期快照和派生结果拒绝；重复帧 PNG 确定性。
- 编辑：100 次真实 patch + 20 次 undo，revision 单调增加；默认 dryRun 不改内存/历史/journal；相同版本的并发修改只成功一次；weapon 接管 x/y 时拒绝无效修改。
- 提交：精确 candidateHash、私有控制通道授权、源基线备份、新修订原子创建、requestId 同请求重取及不同请求拒绝、重开后的来源索引。
- 故障：journal 失败不发布编辑，备份失败不落资产，发布后故障按目标哈希裁决；真实子进程强杀后不因离线接管，核对死亡后取得新 generation；磁盘漂移与损坏末行分别归档。
- HTTP：token、Origin、控制隔离、页面禁止上报文档版本、体限、20/s 限流、版本头、截图超时及 derived 注入 review 拒绝。
- 真实 stdio：镜像模式、rotate schema 与调用、PNG image 内容块，以及隔离 attached 的 patch→内存求解→图像→授权保存→幂等回执。

完整测试通过不等于真实美术角色通过。当前 npc1 准备姿态仍有 7 项必要关系失败；没有重新批准它，也没有本轮 Spine 编辑器导入结论。
