# 创作可用性工单本批交付与未完成项

本批已交付可复核的工程功能和隔离试用路径；**整个 CU 工单仍未关闭**。正式依据为 [工单](creation-usability.md) 和 [机器证据索引](creation-completion-implementation-20261027.json)，不以工具数量或回归通过替代真实作品。

## 本批可操作的功能

- 正式 MCP 创建、冻结和找回创作任务，选择阶段或已保存修订；合法失败姿态可以进入独立内存诊断阶段，继续修改、看图、撤销及重启恢复。失败不能获得正式提交资格。
- 身体、头部与已审查躯干坐标内的末端意图；单臂独立校准、真实世界投影长度求解、手部方向和尺寸补偿。创建校准时即生成批准前连续诊断，不需要先造一段正式 motion。
- motion 明确区间的内部参数、批准关键姿态引用和时间编辑；保持边界、区间外、身份、支撑及分支，支持撤销、重做、恢复、备份另存和重开。
- 官方 player 页面播放、暂停、时间控件及关键姿态定位；呈现绑定文档版本、候选、动画及相机，播放不产生批准。
- 中文工具目录、默认摘要与按需详情；本批新增三个工具，合计 115 项。包内版本/文件校验、隔离启动和恢复来源说明不修改全局 Agent 配置。

## npc1 真实试用的边界

第一次 0.55–1 单臂缩短虽然数值通过，但独立查看实际切片后退回，失败记录保留。随后**另建**固定身体、视向、弯曲分支、宽度为 1 的 0.85–1 校准，独立查看当前四张真实 player 图与 33 帧连续诊断后批准。没有迁移旧诊断批准或把原范围悄悄改成通过。

新范围内的 1 和 0.9 两个姿态重新捕获、审查并备份保存，再组装 1 秒的 `arm_projection_trial`。实际 player 画面与已审查样本逐像素一致，motion 数值通过；真实浏览器已验播放、暂停与阶段定位。本机官方 Spine 4.1.24 成功导入精确候选并保存 `.spine`，候选哈希不变。这个短动作证明受限控制路径有效，**不是原 GIF 的身体动作交付**，也没有提交到角色源动画。

官方导入证据仅覆盖解析和工程保存；编辑器贴图、画面及完整作品仍需分别验收。

## 工程验证与效率

构建、完整回归及原始黄金帧重验的精确日志/哈希见机器索引。原 PNG、实际 player 捕获和资源没有重写；只在当前默认回放通过真实回读与原像素门限后重新登记代码版本，三张最大通道差均为 1，门限仍为 8。

性能对照使用同一冻结起始帧请求、同构建/环境，预热后每模式每轮 30 个样本，共三轮。附着和分离模式比较失败项一致；这证明输入及质量口径一致，不证明完整动画成功或效率提升。额外的状态、帧、修改、撤销和保存微预算另行计量，不能混入适配调用数来制造收益。准备与执行成本分别保留，实际 token 无客户端记录，保持未知。

最新三轮仍有端到端超预算，CU-6 保持未完成。原预算不改；真实 player capture 与页面重载尚未形成三轮预算样本，不能用功能点击通过代替性能通过。

解包试用验证先无依赖执行文件校验，再只读复用本机现有依赖；验证模块篡改拒绝及恢复、实际 stdio 发现、全新隔离启动/看图、输入不变和关闭后 Writer 释放。ZIP 不含 node_modules、角色、旧 journal、凭据或批准。本机验证不代表全新系统安装、目标 Agent 客户端或 WinForms/WebView2 新发行包已验收。
