## 接口与行为

- `spine_start_creation_task`、`spine_get_creation_task`、`spine_select_creation_stage` 关联 taskId/projectId/角色/参考/sequencePath/stageId/完整 VersionRef 与产物，不另建文档版本、求解器或 Writer。机械编排复用现有工具，参考标注/批准仍逐项执行。
- 常用 MCP 返回 `responseDetail:summary|full`，默认摘要，完整核验不裁剪。摘要保留版本、失败总数、详情和图像引用；建议先过滤 capability/readiness，不建议换身份、改支撑或放宽门限。
- 结构合法失败候选允许进入内存诊断草稿、查看和修正，正式资产/源动画授权继续拒绝。可靠证据冲突、必要点未知须明确说明。
- Host 展示参考/当前/前次候选、观测方法及编辑/审查/组装/提交的不同资格；页面不绕 MCP 写 JSON。
- `spine_adjust_pose_intent` 将已校准身体参数落到共享命令。正式单臂透视独立校准模式绑定校准文件/哈希；纵向 0<ratio<=1，宽度未校准保持 1；不从 scale 猜前后，旧诊断批准不迁移。
- motion 区间只修改声明参数/姿态引用/时间，边界冲突拒绝；播放身份包含版本/候选/动画/时间/相机。截图暂停到明确时间并核验，播放不批准。

## 验证与交付约束

覆盖取消/失联/旧版本/旧证据/重试/恢复，恢复前展示来源和差异；可靠轮廓/两点降级/未知误差/冲突/不可达/分支/缩放正反例；真实干净 player 图检查轮廓、接缝、头向、支撑、连续性。绑定、参考、数值/runtime、Agent 视觉、编辑器导入分开报告。

沿用 P95 state<20ms、frame<50ms、patch至图<120ms、undo事务<50ms、undo至图<120ms、commit<200ms、capture<1.5s、页面重载<800ms；记录冷/热缓存、环境、资源规模，逐轮判定，不自动放宽。token 无真实客户端记录则 null，不以字符换算。

TS 修改构建，核心 JSON 修改完整测试；按 AGENTS.md 同步中文清单、README、安全/规范/自然语言/预览/WinForms 相关文档。V1 只写 4.1.24 动画时间线，默认 dryRun、备份、官方规范/diff/引用及唯一 Writer 不变。编辑器导入失败先恢复可用备份再制作。隔离试用不授予生产资格，原两周观察及人工评审保留。
