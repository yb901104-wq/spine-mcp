# 准备姿态适配与修正闭环

## 本轮范围与实际结论

本轮只处理 npc1 初始准备姿态，不批准完整攻击。新增动作级身份校验、躯干轴比较和有界局部修正。通过 MCP SDK stdio 客户端调用构建后的真实 Server，生成参考标注、绑定图、修正前后图和独立诊断候选。

2026-10-10 的实例结果：必要关系指标和数值检查通过，Agent 视觉审查退回。目标前侧拳头仍贴近下巴，与参考的外伸握持轮廓有明显差异。因此准备姿态尚未完成验收；诊断文件不取得提交令牌。程序通过仅证明实际节点满足当前标注，不证明标注准确或切片轮廓复刻成功。

## 动作级对应记录

所有阶段引用同一 sequence JSON，工具路径使用当前已登记 projectId 的相对路径；兼容环境变量工作区。

```json
{
  "version": 1,
  "id": "right-staff",
  "basis": "根据袖口、肘及用户确认追踪解剖身份",
  "confirmedBy": "Agent",
  "confirmedAt": "2026-10-10T04:00:00Z",
  "correspondence": {
    "left": "left",
    "right": "right",
    "basis": "同侧解剖对应",
    "anatomicalIdentity": "ys右臂、zs左臂；腿需独立核实",
    "projectedOrder": "画面前后可改变，解剖身份不改变"
  },
  "weaponHand": "right",
  "visualRigPath": "rigs/npc1.visual-rig.json",
  "visualRigFingerprint": "由已确认绑定计算",
  "stages": [
    {
      "stageId": "ready",
      "referencePosePath": "references/ready.reference.json",
      "referenceFingerprint": "由已审查参考计算"
    }
  ]
}
```

姿态保存 sequencePath 和 stageId。对应、参考、绑定、资源及姿态修改使相关报告和审查失效。旧文件可读取和诊断，旧批准不自动继承。单姿态检查所选阶段和全局身份，其他阶段的失败仍阻止整组通过。

## 调用顺序

1. 标注并审查参考；保留遮挡估计、置信度和未知点。校准 visualRig，检查切片分解、视觉锚点及视角配置。
2. 保存共享动作记录，调用 spine_validate_pose_sequence。可传 posePaths 检测旧阶段混用交换对应。
3. 调用 spine_retarget_reference_pose，传 referencePosePath、visualRigPath、standardPosePath、posePath、sequencePath、stageId。默认 dryRun 在内存中完成方向初值和联合修正，不生成文件；dryRun:false 只保存工作流草稿及报告，不写角色 JSON。
4. spine_compare_pose_graphs 回读官方 runtime 实际视觉节点。必要指标不能被总误差抵消。
5. 如需再次修正，spine_refine_reference_pose 传 posePath、outputPosePath 和可选 comparisonPath。报告必须为最新静态报告，修订必须使用新路径。默认仅计算；detailed:true 可返回完整数据，通常使用摘要及磁盘报告避免大量顶点数据占用上下文。
6. spine_render_pose_comparison 输出参考在上、目标在下的干净图和诊断图。spine_review_pose 记录每项具体理由及图片证据。绿色连线不能代替干净图视觉判断。
7. 只有全部审查通过，才进入原有 motion、完整动画审查、dryRun 和安全事务。失败候选只能诊断，不能构建正常 motion 或正式写入。

## 比较和修正的边界

新校准绑定保存 torsoAxis.version=1。躯干轴由肩中心到髋中心计算，与头部位置无关。身体中心到头中心的连线仅作非必要诊断指标；它不代表实际头部朝向。头部参数独立保存，外观朝向仍由视觉审查确认。

版本化策略为 policies/pose-comparison.v2.json。方向、屈曲门限仍为15°，归一化站距、手位和握距仍为0.15；增加弯曲侧和前后站位必要检查，不支持提交时放宽。近伸直2°内不能假称参考弯曲侧明确。握持杆按无向轴比较，不能因180°等价轴推动双手换位。

先用参考两段方向和目标链长构造初值，再通过官方 runtime 回读修正。接地初值不平均两侧高度冲突，分别保留残差；身体变化后重新换算视觉末端偏移。标准站姿不覆盖参考腿姿及手位。

阻尼最小二乘最多60次迭代，使用有限差分及回溯步长，只接受残差改善。身体位置、旋转和手脚目标可变；身份、支撑及确认的弯曲分支固定。位置相对初值范围±1个归一化单位，身体和脚角±45°，手角±90°；有假想武器约束时固定手目标。水平身体位移增加固定自由度的先验，防止无意义漂移。每一步回读实际节点，最终逐项判定，不以总分批准。到达上限保留最佳候选并说明未满足关系，不宣称全局无解。

错误分类：inputMissing、identityConflict、calibrationMissing、unreachable、relationMismatch、resourceCapability。未确认侧背配置返回能力问题，不能隐藏五官冒充侧背能力。加权网格支持实际顶点回读，但不宣称具备任意网格锚点的通用反向求解。

## 重跑与验收

scripts/acceptance-ready-refinement.mjs 使用真实 MCP stdio 调用：prepare 生成输入及审查图；Agent 看图后填写 review-reasons.json；solve 生成候选；再次看图后填写 final-review.json；finalize 记录通过或退回，并导出诊断静态候选及 runtime 报告。脚本不自行生成视觉批准。

测试包括不同名称和比例的合成夹具、旧 npc1 负例、身份冲突、未知点、视角能力、过期报告、修订失效及 dryRun 不落盘。合成夹具仅验证算法通用性，不能替代第二个真实美术角色的视觉验收。

验收分别列出绑定校准、参考关系、Agent 视觉、数值/runtime 和编辑器导入。当前实例编辑器导入未执行，原 JSON、atlas 和 PNG 不变；现有 exe 未重新打包。
